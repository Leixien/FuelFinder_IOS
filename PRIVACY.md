# Privacy

*English below.*

## Italiano

L'app non raccoglie, non salva su server e non condivide dati personali.

- **Posizione**: serve solo a trovare i distributori vicini. Viene usata sul telefono e non viene mai inviata a nessuno. Puoi negare il permesso: l'app resta utilizzabile esplorando la mappa a mano.
- **Rete**: l'unica richiesta è lo scaricamento del file pubblico dei prezzi (`https://leixien.github.io/FuelFinder_DATA/stations.json`, servito da GitHub Pages). La richiesta non contiene la tua posizione né identificativi. Come ogni server web, GitHub può registrare indirizzo IP e data della richiesta secondo la propria informativa.
- **Preferenze**: carburante, self/servito, ordinamento e tema restano sul telefono.
- **Niente** account, pubblicità, analytics, tracciamento o librerie di terze parti.

Fonte dei prezzi: MIMIT – Osservaprezzi Carburanti (licenza IODL 2.0).

Domande: apri una issue su https://github.com/Leixien/FuelFinder_IOS/issues.

## English

The app does not collect, store on servers, or share personal data.

- **Location**: used only to find nearby stations. It is processed on the phone and never sent anywhere. You can deny the permission and still browse the map by hand.
- **Network**: the only request downloads the public price file (`https://leixien.github.io/FuelFinder_DATA/stations.json`, served by GitHub Pages). It carries neither your location nor any identifier. Like any web server, GitHub may log the IP address and time of the request under its own privacy statement.
- **Preferences**: fuel, service mode, sort order and theme stay on the phone.
- **No** accounts, ads, analytics, tracking or third-party libraries.

Price source: MIMIT – Osservaprezzi Carburanti (IODL 2.0 licence).

Questions: open an issue at https://github.com/Leixien/FuelFinder_IOS/issues.
