# Fase 2 — UI MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sostituire il placeholder con l'app vera: mappa a tutto schermo con prezzi sui pin, foglio persistente con la card "Più economico", lista, dettaglio distributore, Info e interruttore tema.

**Architecture:** La logica pura (classifica, raggio, freschezza, righe del dettaglio, tema) sta in `Domain/Logic` ed è testata a unità. Un solo `@Observable @MainActor` `HomeViewModel` orchestra repository, posizione e filtri; le View sono sottili. Le dipendenze (repository, posizione, orologio) entrano da `AppEnvironment`, che in modalità UI-test usa la fixture, una posizione fissa e un orologio fermo.

**Tech Stack:** Swift 6, SwiftUI (iOS 17), MapKit SwiftUI, CoreLocation, Swift Testing, XCUITest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-29-fase2-ui-design.md` (leggere insieme a questo piano).

## Global Constraints

- iOS 17.0, `SWIFT_VERSION 6.0`, strict concurrency complete. SwiftUI puro; nessuna dipendenza esterna; MapKit.
- `@Observable` (mai `ObservableObject`), `async/await` (mai `DispatchQueue`).
- Nessuna stringa hardcoded nelle View: tutto in `Fuel/Resources/Localizable.xcstrings`, IT base + EN, ogni nuova chiave tradotta.
- View → ViewModel → repository; nessuna rete fuori da `Data/Remote`.
- Attribuzione nella Info testuale e completa: "Fonte dati: MIMIT – Osservaprezzi Carburanti" con link `payload.source.url`.
- Mai "Prezzi Benzina" nel codice o nelle stringhe.
- Ogni nuova View ha una `#Preview` che usa `PreviewData`.
- Dopo ogni task: `xcodegen generate`, build, test, `swiftlint --strict` verdi (comandi in `CLAUDE.md`; in locale aggiungere `-collect-test-diagnostics never` a `xcodebuild test`).
- Commit in inglese `type(scope): subject`, **senza** trailer `Co-Authored-By` né riferimenti a Claude (regola di `CLAUDE.md`).
- Valori fissati dalla spec: raggi `[5_000, 10_000, 25_000]` m; prezzo "vecchio" se `updatedAt` > 7 giorni; banner se `pricesReferenceDate` > 48 h; ricalcolo dopo ≥ 200 m di spostamento; prezzi 3 decimali; `€/kg` per `metano` e `gnl`, `€/l` altrimenti.

## Review Focus

1. **Orologio vs fixture**: i prezzi della fixture sono del 2026-10-27; con l'orologio reale tra una settimana sarebbero tutti "vecchi" e la card resterebbe vuota nello UI test. Atteso: in modalità UI-test l'orologio è fermo a `2026-10-28T12:00:00Z` (Task 4, test in Task 9).
2. **`name` e `brand` vuoti** (~10 impianti reali): la card non deve mostrare una riga vuota. Atteso "Distributore" (test in Task 2).
3. **Posizione non ancora nota** (permesso appena dato, primo fix in arrivo): atteso stato "Cerco la tua posizione…", non "Posizione disattivata" (test in Task 5).
4. **Carburante raro** (gnl/hvo) senza impianti entro 25 km, e cambio carburante dopo: atteso stato vuoto, poi ricalcolo corretto (test in Task 5).
5. **Refresh fallito con cache presente**: nessun errore bloccante, dati mostrati, banner con "offline" solo se anche vecchi (test in Task 5).

### Task 1: Classifica, raggio e freschezza (Domain)

**Files:**
- Create: `Fuel/Domain/Logic/StationRanking.swift`, `Fuel/Domain/Logic/DataFreshness.swift`
- Modify: `FuelTests/Support/TestSupport.swift` (`FuelPrice.stub` riceve `updatedAt: Date = .now`)
- Test: `FuelTests/Domain/StationRankingTests.swift`, `FuelTests/Domain/DataFreshnessTests.swift`

**Interfaces:**
- Consumes: `StationFilter.nearby(_:fuel:mode:origin:radius:)`, `StationMatch`, `ServiceMode`.
- Produces:
  ```swift
  enum SortOrder: String, CaseIterable, Sendable { case price, distance }

  struct NearbyResult: Sendable, Equatable {
      let radius: Double            // metri effettivamente usati
      let matches: [StationMatch]   // ordinati secondo SortOrder
      let cheapest: StationMatch?
  }

  enum StationRanking {
      static let radii: [Double] = [5_000, 10_000, 25_000]
      static let maxPriceAge: TimeInterval = 7 * 24 * 3600
      static func isFresh(_ price: FuelPrice, now: Date) -> Bool
      static func qualifiesForCheapest(_ match: StationMatch, mode: ServiceMode, now: Date) -> Bool
      static func search(_ stations: [Station], fuel: FuelType, mode: ServiceMode,
                         origin: CLLocationCoordinate2D, sort: SortOrder, now: Date) -> NearbyResult
  }

  enum DataFreshness {
      /// nil se i dati hanno ≤ 48 h, altrimenti i giorni interi trascorsi (minimo 2).
      static func staleDays(pricesReferenceDate: String, now: Date) -> Int?
  }
  ```

Regole di `search`: per ogni raggio in ordine, `StationFilter.nearby`; ci si ferma al primo raggio con almeno un match che `qualifiesForCheapest` (modalità uguale a quella scelta **e** fresco). Se nessun raggio qualifica: raggio 25 000, `matches` = quelli entro 25 km (anche non qualificati), `cheapest` = nil. `cheapest` = minimo prezzo tra i qualificati, parità → minore distanza. Ordinamento `.price`: prezzo crescente, parità distanza; `.distance`: distanza crescente. `pricesReferenceDate` è `yyyy-MM-dd` interpretato a mezzanotte `Europe/Rome`.

### Task 5: HomeViewModel

**Files:**

**Interfaces:**
- Consumes: `AppEnvironment`, `StationRanking.search`, `DataFreshness.staleDays`, `LocationUpdate`.
- Produces:
  ```swift
  @Observable @MainActor final class HomeViewModel {
      enum Content: Equatable {
          case loading                       // nessun dato ancora
          case locating                      // dati pronti, posizione autorizzata o in attesa ma senza fix
          case locationDenied
          case results(NearbyResult)         // anche con matches vuoto = stato "nessun distributore"
          case failed(DataError)             // solo senza cache
      }
      private(set) var content: Content
      private(set) var staleBanner: StaleBanner?   // struct StaleBanner: Equatable { let days: Int; let offline: Bool }
      private(set) var payload: StationsPayload?   // per la Info (date, source)
      var fuel: FuelType      // persistito, chiave "filter.fuel", default .benzina
      var mode: ServiceMode   // "filter.mode", default .selfService
      var sort: SortOrder     // "filter.sort", default .price
      var selectedStationID: Station.ID?
      init(environment: AppEnvironment, defaults: UserDefaults = .standard)
      func start() async     // cached() → content; se authorization == .notDetermined chiama requestAuthorization() (primo avvio, spec §4.2);
                             // poi refresh(); poi consuma location.updates() finché il Task non viene cancellato
      func retry() async
  }
  ```
